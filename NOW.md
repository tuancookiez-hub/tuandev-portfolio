The Creative world is live as one continuous WebGPU/TSL raymarched Gargantua journey. The old polygon/R3F anatomy renderer and its `@react-three/fiber` / `@react-three/drei` dependencies are removed.

Scroll/swipe sequence: intact approach → exploded overview → gravitational lens → accretion disk → photon ring → event horizon → singularity → finale. Reverse input reconstructs the sequence one step at a time.

The exploded shader uses one shared photon path with independently translated lens, disk, ring, horizon, and core channels. Overview uses a central intact-system ghost, five connectors, numbered markers, lens/horizon guides, and the caption “one system / five live phenomena.”

Scroll model: normal marathon document scroll (`900vh` desktop, `850vh` mobile) with eight spacious scene regions. Wheel and touch are not intercepted or snapped. The fixed side dots are real buttons: desktop hover/focus/current labels identify each scene, and desktop/mobile clicks smoothly navigate directly to any stop. The renderer performs true scroll scrubbing: camera, channel centers, weights, lensing, horizon scale, bloom, core pinch, and finale collapse interpolate directly from exact normalized scroll progress. Stopping scroll freezes the composition; reverse scroll retraces it.
