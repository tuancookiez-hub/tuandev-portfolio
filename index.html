HyAtlas · v4.5.0 · Open source (Apache-2.0)

Long-term memory for AI agents.

HyAtlas gives an agent a seven-layer memory it keeps across sessions: who you are, what was said, the facts behind it, and a knowledge graph with source citations. One Go binary with local embeddings. No Python, no GPU.

Install HyAtlasJoin the HyAtlas Cloud waitlist

Live today as a memory provider in the Hermes Agent plugin catalog ↗ by Nous Research.

Agents forget. HyAtlas remembers, on your terms.

Pick how much the memory reasons. Every mode keeps the raw trace and searches it with local embeddings.

Lite

No LLM
1 / 7

No extraction call is made, so conversation text never leaves the machine. Raw trace and local BGE embeddings only.

Pro

Per turn
5 / 7

One extraction call per write. Fills profile, facts, summaries and intentions from what each turn actually says.

Ultra

Default
7 / 7

Adds a slow path that reasons across memories and time: it merges contradictions, keeps relations corroborated by more than one turn, and generalises recurring patterns.

Seven layers, one memory.

  1. L1
    Profile

    Who the user is and what they prefer.

  2. L2
    Raw

    The full trace of every turn, always kept.

  3. L3
    Fact

    Discrete facts extracted from a turn.

  4. L4
    Summary

    Compressed recaps of a conversation.

  5. L5
    Knowledge

    Relations corroborated across turns, in a bitemporal graph with source citations.

  6. L6
    Schema

    Recurring patterns across memories.

  7. L7
    Intention

    Goals and plans the user has stated.

Single Go binaryIn-process BGE-small embeddingsEmbedded vector storeLoopback-only, no telemetryLinux · macOS · Windows

Running in two commands.

1 · Install the server
curl -fsSL https://raw.githubusercontent.com/tuancookiez-hub/HyAtlas-Memory/main/scripts/install.sh | bash
2 · Add it to Hermes Agent
hermes plugins install tuancookiez-hub/HyAtlas-Memory/plugins/hyatlas

Where HyAtlas is going.

The local server stays open source. HyAtlas Cloud is the hosted, paid product.

    HyAtlas Cloud: hosted, multi-tenant memory for teams and agent platforms, built on Cloudflare Workers, Durable Objects, Vectorize, D1 and Workers AI.

  • LaterPlanned

    A memory API and SDKs for agent frameworks beyond Hermes.
